# Project Documentation Repository

## Purpose
This directory contains user guides, developer onboarding documentation, deployment runbooks, API references, and limitation records.

---

## Directory Structure
- `01_user_guide.md`: End-user manual, installation guide, workflow walkthroughs, and UI navigation.
- `02_developer_guide.md`: Development setup, environment variables, local testing instructions, and contribution norms.
- `03_deployment_runbook.md`: Build steps, production configuration, Docker / Cloud Run deployment instructions.
- `04_known_limitations.md`: Explicit documentation of unsupported edge cases, scale boundaries, and future roadmap items.

---

## Standards
1. **Self-Contained & Reproducible**: Any developer or user should be able to clone the repository and run the application using these guides.
2. **Synchronized with Code**: Update docs as part of the implementation and repair cycles.
